angular.json - Contains the Angular project configuration and build settings.

tsconfig.json - Contains TypeScript compiler configuration.

package.json - Contains project information, dependencies and npm scripts.

src/main.ts - Entry point of the Angular application.

src/app/app.ts - Root standalone component of the application.

src/app/app.config.ts - Configures providers and application settings.

src/app/app.routes.ts - Defines the application routes.

src/index.html - Main HTML page that loads the Angular application.
