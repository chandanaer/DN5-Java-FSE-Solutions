# Exercise 5 - Git Merge Conflict Resolution

## Objective
To practice Git branching, merging, conflict resolution, and pushing changes to a remote GitHub repository.

## Steps Performed
- Created a local Git repository.
- Created and worked with Git branches.
- Created `hello.xml`.
- Made changes in different branches.
- Compared differences between branches.
- Used P4Merge for visual comparison.
- Merged the GitWork branch into the main branch.
- Identified and resolved the merge conflict.
- Verified the repository status and commit history.
- Connected the local repository to the remote GitHub repository.
- Pushed the completed work to the remote branch.
- Verified the changes on GitHub.

## Tools Used
- Git
- Git Bash
- GitHub
- P4Merge
