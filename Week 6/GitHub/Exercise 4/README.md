# Exercise 3 - Git Branching, Merging and Conflict Resolution

## Objective

To practice Git branching, merging, conflict resolution, and visual difference/merge operations using P4Merge.

## Steps Performed

1. Created a new Git repository.
2. Created an initial commit.
3. Created a new branch named `GitWork`.
4. Created and modified files in different branches.
5. Used Git commands to view and switch between branches.
6. Compared differences between the `main` and `GitWork` branches.
7. Configured P4Merge as the Git diff and merge tool.
8. Used P4Merge to visually compare differences between branches.
9. Merged the `GitWork` branch into the `main` branch.
10. Encountered a merge conflict in `hello.xml`.
11. Used P4Merge to resolve the merge conflict.
12. Saved the resolved file and completed the merge.
13. Verified the final repository status.
